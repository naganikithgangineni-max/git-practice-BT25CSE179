## Assignment Description
This repository contains 15 practical exercises demonstrating Git version control and GitHub collaboration, including repository creation, commits, staging, branching, merging, conflict resolution, recovery operations and remote collaboration.

## Completed Exercises
1. Git installation and configuration
2. Repository initialization and first commit
3. Greeting script with input validation
4. Selective staging of files
5. Inspecting changes using git diff
6. Ignoring generated files using .gitignore
7. Creating and merging a feature branch
8. Merging and deleting a branch
9. Creating and resolving a merge conflict
10. Unstaging and discarding changes
11. Reverting a commit
12. Stashing and restoring unfinished changes
13. Publishing and cloning a repository
14. Feature branch collaboration and Pull Request
15. Fetching and pulling remote updates

## Compile and Run Programs
The shell programs use Bash. Open Git Bash or another Bash terminal.

Greeting program:
```bash
bash exercise-03/greet.sh
```

Menu program:
```bash
bash exercise-03/menu.sh
```

Improved greeting program:
